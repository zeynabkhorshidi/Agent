# گزارش واقعی اعتبارسنجی

تاریخ اجرا: ۱۰ آبان ۱۴۰۵ / ۱ نوامبر ۲۰۲۶. محیط: Linux، Python 3.12، SQLite محلی، Chromium. داده‌ها ساختگی‌اند. هیچ تستی به IP داخلی صوت، OTP واقعی، ERP یا مدل زبانی متصل نشده است.

## نتایج اجرا

- ۲۰ آزمون unittest: **۲۰ موفق، صفر ناموفق، صفر skipped**؛ اجرای نهایی در venv تازه ۰٫۸۰۵ ثانیه. خروجی خام اجرای دیگر ۰٫۸۲۳ ثانیه در `evidence/unit-tests.txt` موجود است.
- مرورگر واقعی: مسیر کامل مشتری جدید متنی، دو محصول، رد پیشنهاد، مرور، تأیید، ثبت و دانلود PDF موفق؛ خطای JavaScript صفر.
- نمای ۱۴۴۰ پیکسل و موبایل ۳۹۰ پیکسل بررسی شد؛ در موبایل سرریز افقی نبود. تصویرها همراه‌اند. این بررسی جای آزمون دستگاه صوت واقعی یا ممیزی جامع دسترس‌پذیری نیست.
- PDF باز شد و به تصویر تبدیل شد. پس از مشاهده حذف حروف لاتین با فونت اولیه، فونت PDF به DejaVuSans تغییر کرد و نمایش فارسی، Sellora، SKU، شماره، تاریخ شمسی و ساعت تهران بصری بازبینی شد. مجوز هر دو فونت همراه است.
- تصویر Docker ساخته شد. اولین اجرای کانتینر مشکل مجوز خواندن فایل برای کاربر غیرریشه داشت؛ Dockerfile اصلاح و تصویر دوباره ساخته شد. اجرای اصلاح‌شده: سلامت پایگاه، مسیر کامل سفارش و PDF با ۲۹۰۳۵ بایت موفق بود.
- نصب از requirements در venv مستقل، migration تکرارپذیر و شروع uvicorn روی پورت ۸۰۰۱ واقعاً اجرا شدند.
- بررسی نحوی Python و هر دو فایل JavaScript موفق بود.

## پوشش معیارهای پذیرش

| سناریو | نتیجه و مرز آزمون |
|---|---|
| ۱. مشتری جدید صوتی و رسید | مسیر **متنی** و PDF موفق؛ صوت واقعی انجام نشده، نیازمند قرارداد |
| ۲. مشتری قبلی و سابقه | احراز **آزمایشی**، نمایش اطلاعات پس از کد و بازیابی سبد موفق؛ OTP/CRM واقعی متصل نیست |
| ۳. چند کالا و ابهام | پرتقال/انبه چندقلمی، محصول مبهم و واحد «دو تا» آزمون شد؛ کاتالوگ واقعی آزمون نشده |
| ۴. اصلاح و حذف/تعویض کانال | اصلاح هم‌زمان دو قلم و تغییر دستی مشترک آزمون شد؛ تعویض صوت واقعی آزمون نشده |
| ۵. قطع صحبت و پاسخ قدیمی | turn_id تکراری سبد را دوباره تغییر نداد؛ barge-in صوتی پیاده/آزمون نشده |
| ۶. online/offline و بازیابی | Router با MockVoice و خطای آنلاین آزمون شد؛ سرویس صوت واقعی و جابه‌جایی شبکه آزمون نشده |
| ۷. خطای وابستگی‌ها | خطاهای Adapter و نبود هر دو مسیر صوت پوشش دارد؛ خطای واقعی STT/TTS/LLM/ERP جداگانه آزمون نشده |
| ۸. تغییر قیمت/موجودی | تغییر قیمت، انقضا، نسخه سبد و تعداد بیش از موجودی رد شدند؛ تغییر هم‌زمان موجودی در سامانه خارجی آزمون نشده |
| ۹. ثبت تکراری | دو درخواست هم‌زمان با کلید/مرور مشترک فقط یک سفارش ساختند؛ قطع شبکه واقعی شبیه‌سازی نشده |
| ۱۰. رد پیشنهاد | مسیر ثبت بعد از رد پیشنهاد موفق بود |
| ۱۱. نبود تأیید/داده ناقص | رد ثبت بدون تأیید و مرور با اطلاعات ناقص آزمون شد؛ پیام موفقیت فقط پس از پاسخ موفق سرور ظاهر شد |
| ۱۲. دسترسی دیگران | دریافت رسید مشتری دیگر ۴۰۴؛ کاربر احرازنشده ۴۰۱؛ اپراتور بدون مجوز دریافت رسید ۴۰۳ |
| ۱۳. PDF و تاریخ/جمع | PDF معتبر، جمع دو قلم ۹۹۰٬۰۰۰ تومان و تاریخ/ساعت تهران بصری بررسی شد؛ چاپ فیزیکی انجام نشده |
| ۱۴. عدم دسترسی صوت | UI اتصال‌نداشتن صوت را اعلام و متن را حفظ می‌کند؛ چون صوت تنظیم نیست، مجوز میکروفون درخواست نمی‌شود؛ رد واقعی permission آزمون نشده |

آزمون‌های اضافی: نرمال‌سازی ی/ک و موبایل +۹۸، خروج/ورود و بازیابی، توقف/ادامه، شروع مجدد تأییدشده، محدودیت نقش‌ها، Origin نامعتبر، موجودی، ذخیره از اتصال DB مستقل.

## سنجش عملکرد محلی

آخرین اجرای مرورگر با سرور venv:

- زمان ارسال متن تا آماده‌شدن ورودی پس از پاسخ، هشت نوبت: ۶۰٫۵۹، ۹۵٫۸۴، ۸۰٫۵۹، ۷۹٫۳۰، ۸۱٫۳۵، ۶۱٫۸۶، ۶۷٫۱۷، ۷۷٫۱۶ میلی‌ثانیه.
- کلیک ثبت تا نمایش موفقیت: ۱۵۶٫۶۷ میلی‌ثانیه.

این اندازه‌ها شامل تعامل محلی مرورگرند؛ معیار پایان گفتار تا پخش پاسخ، زمان مستقل تشخیص محصول، توان عملیاتی سازمانی یا SLA سرویس واقعی نیستند. آن معیارها اندازه‌گیری نشده‌اند. نتیجه خام در `evidence/browser-result.json` است. benchmark بار، WebSocket، VPN، failover واقعی و LLM انجام نشده‌اند.

## وضعیت اتصال‌ها

**واقعاً پیاده و اجراشده:** رابط RTL، متن مرحله‌ای، کاتالوگ نمونه، قواعد اصلاح سبد، ثبت SQLite تراکنشی و idempotent، PDF، سفارش‌های مشتری، پنل نقش‌دار و قیمت نمونه، دستورهای Docker و ابزار نگه‌داری.

**آزمایشی:** تمام محصولات/موجودی/قیمت‌ها، هویت با کد ثابت، پیشنهاد مکمل و ثبت سفارش محلی. نقش‌ها برای توسعه رمز مشترک هر نقش دارند؛ SSO فردی نیستند.

**نیازمند اتصال یا توسعه:** صوت واقعی و barge-in، فهرست صدا، کاتالوگ شرکت، OTP، مشتری/CRM، قیمت/موجودی/ERP، پرداخت، LLM، PostgreSQL چندگرهی، S3، سیاست چندآدرسی، کمپین و تحلیل پیشنهادهای تاریخی، VoIP و انتقال اپراتور. شرایط موردنیاز دقیقاً در INTEGRATIONS.md آمده است. این نسخه آماده استفاده از داده واقعی یا فروش عملیاتی معرفی نمی‌شود.
