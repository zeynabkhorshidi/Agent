# گزارش نسخه اتصال STT

تاریخ: ۱۳ آبان ۱۴۰۵ / ۴ نوامبر ۲۰۲۶. این گزارش جایگزین نتیجه تاریخی نسخه بدون صوت است؛ گزارش قدیمی برای سابقه محفوظ مانده است.

## نتیجه‌های انجام‌شده

- Python 3.12 در venv: **۴۱ آزمون موفق، صفر شکست و صفر skipped**، زمان اجرای نهایی ۱٫۲۹۱ ثانیه. ۲۰ آزمون قبلی سفارش و ۲۱ آزمون جدید Adapter/کانال صوت. خروجی خام: `evidence/voice-unit-tests.txt`.
- قرارداد multipart واقعی `file`، نام فایل، مسیرهای دقیق آنلاین/آفلاین، engine و schema پاسخ بررسی شد. httpx.MockTransport فقط پاسخ موتور/شبکه را کنترل می‌کند؛ دقت STT را نمی‌سنجد.
- fallback در 502 و timeout، عدم fallback در 400/413/422 و مجوز 401/403، Offline اجباری، Online اجباری، خرابی هر دو مسیر، پاسخ ناسازگار، circuit باز و بازیابی پس از cooldown آزمایش شد.
- API: نشست، Origin نامعتبر، پسوند/فایل خالی/حجم، محدودیت نرخ، شناسه تکراری با payload یکسان/متفاوت، لغو پیش از پردازش/در میانه/پس از نتیجه، عدم افشای متن در ممیزی و عدم تغییر سبد یا مکالمه با transcript آزمون شد.
- بازبودن SQLite در ویندوز می‌توانست پاک‌سازی فایل را مختل کند؛ اتصال‌ها اکنون در خروج از context بسته می‌شوند. تست‌ها پایگاه موقت مستقل دارند و به داده توسعه وابسته نیستند.

## مرورگر واقعی

Chromium با MediaRecorder و **دستگاه میکروفون مصنوعی مرورگر**، بک‌اند Sellora و یک HTTP server کنترل‌شده مطابق قرارداد STT اجرا شد. این تست فقط در `tests/stt_contract_server.py` است و در برنامه اصلی ثبت یا اجرا نمی‌شود.

موفق: ضبط/توقف، چند نوبت مشخصات، متن قابل اصلاح قبل از ارسال، ورود چند قلم، ارسال فایل، خطای آنلاین و استفاده از آفلاین، اصلاح دو قلم، لغو ضبط، کنارگذاشتن پاسخ دیررس، حفظ متن تایپ‌شده در حین تبدیل، رد اجازه میکروفون و ادامه متنی، تأیید نهایی، ثبت پایدار و دانلود PDF. صفر خطای JavaScript. نمای دسکتاپ ۱۴۴۰ و موبایل ۳۹۰ پیکسل بدون سرریز افقی بررسی شد.

نتیجه خام و تصویرها: `evidence/voice-browser-result.json`، `voice-desktop.png`، `voice-mobile.png`، `voice-order-receipt.pdf`.

زمان توقف ضبط تا نمایش متن در fixture، هفت نوبت: ۹۳٫۰۵، ۷۰٫۸۶، ۷۰٫۱۰، ۷۷٫۱۰، ۶۳٫۵۶، ۶۷٫۲۱، ۷۶٫۰۵ میلی‌ثانیه. این‌ها **تأخیر موتور واقعی، پایان گفتار تا پخش پاسخ یا SLA سازمانی نیستند**. سرویس کنترل‌شده هیچ استنتاج صوتی انجام نمی‌دهد.

## Docker و بسته

تصویر `sellora:voice` با TLS verification فعال ساخته شد. داخل کانتینر غیرریشه، یک سرویس HTTP کنترل‌شده در loopback و برنامه اصلی با Adapter واقعی اجرا شدند: سلامت، هفت نوبت multipart، ارسال متن به منطق فروش، ثبت سفارش و دریافت PDF موفق بود. مدل Whisper، Torch یا FFmpeg در تصویر Sellora نصب نمی‌شود؛ آن‌ها مربوط به سرویس مستقل شرکت‌اند.

`pip check` ناسازگاری نداشت؛ بررسی نحوی Python و هر سه فایل JavaScript و `git diff --check` موفق بود. اسکریپت ویندوز افزوده شده اما روی Windows واقعی اجرا نشده است؛ آزمون اجرا روی Linux/Chromium انجام شده است.

## آنچه هنوز واقعاً آزمون نشده

درخواست GET به health توسعه `172.20.3.81:30089` از محیط ساخت پاسخ HTTP **403** گرفت؛ پاسخ موفق health و استنتاج سرویس شرکت مشاهده نشد. این خطا اثبات خرابی سرویس نیست. اتصال از شبکه مجاز شرکت/VPN، دقت Google یا Whisper، فارسی واقعی، نویز/لهجه، بار هم‌زمان، صحت مدل آفلاین و latency واقعی همچنان باید روی زیرساخت شرکت آزمایش شوند. سرویس عملیاتی فراخوانی نشده است.

فایل‌های ارسالی کاربر مستندات و app سرویس STT بودند؛ پوشه stt، UI سرویس و مدل ضمیمه نبودند. هیچ ادعایی مبنی بر بازسازی سرویس یا دانلود مدل نمی‌شود. TTS و فهرست صدا در قرارداد ارائه‌شده وجود ندارند؛ پاسخ Sellora فعلاً متنی است. اتصال قیمت/موجودی/کاتالوگ/OTP واقعی نیز جزو این تغییر نیست و نشان آزمایشی آن‌ها حفظ شده است.
