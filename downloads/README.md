# دریافت Sellora

نسخه ایجنت فروش با API متریال و عکس کاتالوگ، ایران‌سنس، تم سفید/سرمه‌ای و دیتابیس پایدار.

برای نمایش در ویندوز `start-demo-windows.cmd` را اجرا کنید: ۴ فروشگاه، ۶ خریدار، دو محصول عیناً از نمونه کاتالوگ ارسالی مالک و قیمت/موجودی و سابقه خرید ساختگی در دیتابیس جدا. کد احراز توسعه ۱۲۳۴۵۶ است و پیامکی ارسال نمی‌شود.

برای اجرای عادی `start-windows.cmd` و برای دریافت کاتالوگ از شبکه دارای دسترسی `sync-catalog-windows.cmd` ارائه شده‌اند. اتصال واقعی کاتالوگ و مدل STT از محیط ساخت به دلیل محدودیت شبکه تأیید نشده؛ LLM/TTS و منابع تجاری/احراز واقعی نیز به تنظیم نیاز دارند.
