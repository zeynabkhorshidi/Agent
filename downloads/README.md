# دریافت Sellora

فایل Sellora.zip شامل نسخه‌ای است که هیچ کالای نمونه یا عکس عمومی در اجرای عادی ندارد. فقط محصول دریافت‌شده از کاتالوگ شرکت در ویترین نمایش داده می‌شود. دریافت واقعی کاتالوگ و عکس سن‌ایچ از محیط ساخت به دلیل محدودیت دسترسی هنوز انجام نشده است.

منبع بسته: `1043aaf9d14bda37000d2eea04a8840a7cbd56c2`.

اسکریپت start-windows.cmd برای اجرا و check-voice-windows.cmd برای تشخیص اتصال STT روی سیستم کاربر است. ضبط کم‌صدا و WAV اصلاح و با گیرنده کنترل‌شده بررسی شدند؛ خرابی خاص مدل شرکت بدون دسترسی واقعی و گزارش خطای کاربر، رفع‌شده معرفی نمی‌شود.

۶۸ آزمون موفق؛ گزارش فعلی در docs/CATALOG_AND_STT_FIXES.md.
