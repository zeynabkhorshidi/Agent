# Sellora — اصلاح اتصال صوت

راهنمای جدید: docs/STT_CONNECTION_REPAIR.md.

۹۵ تست موفق. علت هر مسیر STT، reset/پروکسی/TLS و کد پیگیری خطا حفظ می‌شوند. سلام اولیه و اجازه پخش رسانه اصلاح شده‌اند. آزمون پخش صوت کنترل‌شده در Chromium موفق است؛ این به معنی تأیید مدل واقعی شرکت نیست.

فایل integrations/stt/docker-compose.fixed.yml باید کنار Dockerfile اصلی پروژه مستقل STT استفاده شود. Dockerfile ارسالی STT روی 8123 اجرا می‌شود ولی compose قبلی 8000:8000 بود. مسئول مجاز باید پورت واقعی استقرار و نگاشت بیرونی را تأیید کند؛ استقرار زنده از این محیط تغییر نکرده است.

اجرای نمایش Sellora: start-demo-windows.cmd. تشخیص اتصال: check-voice-windows.cmd. داده واقعی شرکت و تست زنده مدل تأیید نشده‌اند.
