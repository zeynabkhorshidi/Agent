# دریافت پروژه Sellora

فایل `Sellora.zip` شامل سورس رابط مشتری، پنل مدیریت، جریان سفارش، رسید PDF و اتصال STT است. پس از استخراج، فایل `start-windows.cmd` را اجرا کنید. داده‌های مشتری و فروش همچنان آزمایشی‌اند؛ دسترسی به سرویس صوت شرکت نیازمند شبکه مجاز شرکت است.

منبع این بسته: commit `eaa73cf2bc8ef96a41cbeaa9d3dee797e544cb9a`. دستورهای اجرا و گزارش ۴۱ آزمون داخل بسته هستند. مدل صوتی یا سورس ناقص سرویس مستقل شرکت به جای Sellora بسته‌بندی نشده است.
