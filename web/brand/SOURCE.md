# منابع برند

sellora-mark.svg: نشان اختصاصی S با خروجی برداری، ساخته‌شده برای همین پروژه.

sayesaman.svg: بازترسیم برداری از مرجع لوگوی سایه‌سمن که مالک پروژه در گفت‌وگو فرستاد. متن لوگو بخشی از نشان است. برای خروجی نهایی برند، فایل برداری رسمی می‌تواند مستقیماً جایگزین این فایل شود.

هیچ عکس محصول عمومی یا تولیدشده برای پرکردن کاتالوگ استفاده نشده است.
